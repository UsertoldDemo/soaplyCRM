# Soaply CRM

Soaply CRM is the public companion project for a demonstration of [UserTold](https://usertold.ai/), a platform that turns real user feedback into evidence-backed product work.

The application is a fictional soap-factory CRM used in a recorded usability test. It gives the participant realistic workflows for finding customers, updating account information, and scheduling production orders while keeping the product small enough to follow every step from interview evidence to code change.

## What this repository demonstrates

The demonstration follows a complete product-feedback loop:

1. A participant uses Soaply CRM during a recorded user test.
2. UserTold analyzes the session and organizes the supporting evidence.
3. Findings become actionable work in [GitHub Issues](https://github.com/UsertoldDemo/soaplyCRM/issues).
4. Proposed improvements can be reviewed as code changes in [GitHub Pull Requests](https://github.com/UsertoldDemo/soaplyCRM/pulls).

This repository provides a transparent record of that process. The application source, issues, and pull requests can be viewed together to see how observed user problems translate into product decisions and implementation.

## Try Soaply

The live demo is available at [soaply-demo.onrender.com](https://soaply-demo.onrender.com/).

Soaply includes fictional customers, production orders, and tasks. Changes are stored in the browser, so each visitor gets an independent workspace without creating an account.
